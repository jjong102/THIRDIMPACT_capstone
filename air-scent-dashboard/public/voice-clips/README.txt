이 폴더에 녹음 파일을 넣습니다. wav, mp3, ogg, m4a.

더보기 → 음성 → 로드하기를 누르면 이 폴더의 파일이 버튼으로 나옵니다.

파일 이름은 영어·숫자·밑줄(_)만 씁니다. 예: hello_kiring.mp3
  한글·공백·? ! 같은 기호가 들어간 파일 이름은 Windows 에서 저장소를 받을 때(clone) 깨지거나
  Mac·Linux 사이에서 다른 파일로 보일 수 있습니다.

버튼에 보일 한글 이름은 labels.json 에 적습니다.
  { "hello_kiring.mp3": "안녕_끼링이야" }
  (밑줄은 화면에서 띄어쓰기로 보입니다. labels.json 에 없으면 파일 이름이 그대로 버튼 이름이 됩니다.)
