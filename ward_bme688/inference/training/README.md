# training — 녹화·라벨 데이터

원시 데이터는 git 에 올리지 않는다(`.gitignore`). 이 파일만 커밋한다. 수집 절차는 [docs/수집_가이드.md](../docs/수집_가이드.md).

| 폴더 | 무엇 |
|---|---|
| `recordings/` | 녹화 원본 CSV (`rec_날짜_시각_이름.csv`, 센서 8개 × 10단계 가스저항) |
| `data/<라벨>/` | 라벨 구간 (`<녹화>__segN.csv`). 학습(`open_set.py fit`)과 재생 평가(`replay_eval.py`)가 읽는다 |
| `discarded_<날짜>/` | 버린 녹화·라벨. 학습·평가에 안 쓰임. 되돌리려면 원래 폴더로 옮긴다 |
