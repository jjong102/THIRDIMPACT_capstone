### 2026-11-09 · Water(물만 분무) 대조군은 수집하지 않음
- **결정**: 물만 뿌리는 Water 라벨은 모으지 않는다.
- **이유**: 물 전용 분무 장치가 없다(발향 채널 3개는 모두 향 용액).
- **영향**: 습도만으로 생기는 오판은 따로 확인 못 한다. 대신 우리 향은 물 70 mL 에 섞어 뿌리므로 향 데이터에 습도가 함께 들어 있고, **데모 장면(로봇이 와드 옆에서 청정·발향) 녹화**로 수증기+향이 진할 때 식초로 오판하는지 확인한다. 10/08~12 의 "습도 방향 ≈ 향 방향(cos 0.989)" 사실은 그대로 유효.

### 2026-11-09 · 표결에서 켬 쪽도 과반이어야 Unknown (아니면 보류)
- **결정**: 한 라벨 과반도, 우리 향 쪽 과반도 없을 때 예전에는 Unknown(출동 쪽)으로 봤다 → 이제 Unknown·악취 표가 과반일 때만 Unknown, 아니면 보류(Weak).
- **이유**: "라벨 없는 구간 출동" 16번을 하나씩 보니 Unknown 4/8 + 보류 4/8 (|Δ| 0.25~0.30) 같은 경계 신호가 출동으로 이어지고 있었다.
- **영향**: 라벨 없는 구간 출동 16 → 8, 식초 10/10·잘못 출동 1번/224분 유지, 반응 중앙 29 → 35초(최대 60초 그대로). 남은 8번 = 진짜 식초 4, 물 양말 1, 중간 세기 라벤더→식초 2, 차가운 시작 1.

### 2026-11-09 · 와드 ↔ UI Jetson 연동 = MQTT → ROS 2 토픽, 출동 시작은 화면
- **결정**: UI Jetson 의 `ward_bridge_node`(GDM `MQTT_sub_node` 개조)가 `diffuser/+/inference_ward` 를 `/ward/decision`·`/ward/event`(std_msgs/String JSON)로 넘기고, 출동은 지금 화면 흐름(`useScentMissionNav`)이 `ros_nav_bridge` 를 통해 시작한다. 와드↔방은 방 지도 `sensor_id`. 형식은 [INTERFACE.md](../INTERFACE.md).
- **이유**: 기존 ROS·화면 코드를 가장 적게 바꾸고, 주행 Jetson 도 같은 토픽을 볼 수 있으며 rosbag 으로 판정·주행·발향을 한 타임라인에 기록할 수 있다. 출동 로직을 ROS 노드로 옮기는 건 데모 안정성이 필요할 때.
- **영향**: 구현 전 형식만 확정(11/09). `/ward/event` 는 volatile(늦게 켜진 노드가 지난 ON 으로 출동하지 않게). `SPRAY <초>` 명령은 와드 펌웨어에 추가 예정.

### 2026-11-09 · 개발 폴더 = git 저장소 = 팀 저장소 배치, 펌웨어 하나
- **결정**: `C:\2026capston` 을 git 저장소로 만들고 팀 저장소 `ward_bme688/inference/` 는 `tools/publish_team.py` 로 커밋된 트리를 그대로 올린다. 수집용 `ward_usb` 를 없애고 `firmware/ward` 하나(WARD_WIFI 0/1).
- **이유**: 되돌리기·이력이 없었고, 팀 저장소용 README·복사 스크립트가 임시 폴더에 있었다. 펌웨어 두 벌은 히터 설정 불변식을 사람 기억에 맡겼다.
- **영향**: 데이터는 그대로 `training/`(커밋 안 함). 히터 불변식은 `firmware_parity` 가 자동 확인. 공개 저장소에는 CLAUDE.md·docs/ 를 기본으로 안 올린다.

### 2026-11-09 · 판정 코드를 와드 C 한 곳으로 (`ward_engine.py`)
- **결정**: 파이썬 판정 로직(ward_controller 의 기준선·표결·출동·기준선 다시 잡기)을 지우고, PC 도 와드 펌웨어의 `ward_infer.h` 를 gcc 로 빌드해 ctypes 로 부른다.
- **이유**: 같은 규칙을 두 언어로 들고 있으니 고칠 때마다 어긋났다(11/05: 1분으로 바꾸자 일치 47%). 평가 숫자가 와드 실제 동작과 다를 수 있었다.
- **영향**: 규칙 수정은 ward_infer.h 한 곳. PC 에 gcc 필요(Windows MinGW-w64, Jetson 기본 gcc). replay_eval 숫자 = 와드 동작(10/10, 중앙 29초, 잘못 출동 1번/224분). open_set.py 의 predict_one 은 학습 평가·live_view 표시용으로만 남음.

### 2026-11-05 · 갇힘 풀기 60초(라운드 수로 셈) + 원격 기준선 명령
- **결정**: `stuck_rebase` 300 → 60초, 평평한지는 시간 대신 **최근 6라운드**로 본다. 와드에 MQTT `cmd` 토픽(`REBASE`/`REBOOT`)을 두고 `ward_view.py --rebase` 로 보낸다.
- **이유**: 5분은 데모 중 너무 길다. 시간으로 세면 60초 창이 5/6 라운드 경계에 걸려 파이썬과 와드 C 가 다르게 동작(일치 47%) → 라운드 수로 세니 91%. 차가운 시작 문제는 원격 명령이 더 확실하다.
- **영향**: 데모 순서 = 켜고 15분 예열 → `--rebase` → 시작. 판정 규칙 변경은 계속 파이썬·C 동시 수정 + `firmware_parity.py`.

### 2026-11-04 · 판정을 와드 안에서도 (온디바이스) + 무선 모델 교체
- **결정**: 판정 규칙을 C(`ward_mqtt/ward_infer.h`)로 옮겨 와드가 직접 `inference_ward` 를 보낸다. 모델은 MQTT `/model`(retained, CRC-32)로 교체·NVS 저장. Jetson 판정(`ward_controller.py`)은 그대로 두고 비교·백업용.
- **이유**: Jetson·WiFi 지연과 상관없이 와드만으로 데모가 돈다. 모델 갱신을 USB 업로드 없이 할 수 있다(USB+팬+WiFi 는 Brownout).
- **영향**: 판정 규칙을 바꾸면 파이썬·C 둘 다 고치고 `firmware_parity.py` 로 확인. 모델 갱신은 `update_model.py [--push]` 하나로.

### 2026-11-04 · 켜진 채 갇힘 방지 (`stuck_rebase` 300초)
- **결정**: 청정기가 켜진 채 켬 쪽 판정이 300초 평평하면 기준선을 다시 잡는다.
- **이유**: 차가운 센서로 켜자마자 잡은 기준선이 떠서, 공기를 Unknown 으로 봐 3분 넘게 켜진 채로 있었다. 기존 rebase 는 청정기가 꺼져 있을 때만 동작.
- **영향**: 진짜 악취가 5분 넘게 평평하게 지속되면 기준선이 그 악취로 옮겨 꺼질 수 있다 — 데모(양말 60초)에는 문제없음.

### 2026-10-27 · 악취 소품 = 식초에 적셔 말린 양말
- **결정**: 물 100 mL + 3배식초 원액 30 mL 에 양말을 살짝 담갔다 짜고 약 2시간 말려 밀폐 통에 보관. 데모 때 꺼내 센서에 60초 댄다. 대조군은 물에만 적셔 같은 방법으로 말린 양말.
- **이유**: 젖은 식초 양말은 물 양말과 5~6° 로 구분 안 됨(물기 반응). 말린 양말은 물 양말과 14~16°, 우리 향과 27° — 합격 기준 통과. 아래 "식초 보류" 결정을 대체.
- **영향**: 데모 소품에 물기가 없어야 한다. 보관 기간에 따른 세기 변화는 확인 필요.

### 2026-10-27 · 오일 농도 올림 (각 40방울)
- **결정**: 물 70 mL + 오일 **각 40방울** (이전 페퍼민트 15 / 라벤더 20 / 오렌지 20).
- **이유**: 데모 배치(센서를 더 가까이 둘 수 없음)에서 이전 농도의 페퍼민트는 \|Δ\| 0.07 로 거의 안 닿음. 올린 뒤 오렌지 \|Δ\| 0.95(중앙).
- **영향**: 이날부터의 데이터만 이 농도. 더 진하게(원액에 가깝게)는 초음파 진동판 손상 위험이 있어 올리지 않는다.

### 2026-10-27 · 악취 후보 다시 고르기 (식초 보류)
- **결정**: 물에 묽힌 식초 양말은 보류. 황화합물 계열 실제 악취(썩은 달걀·음식물 쓰레기 등) 후보를 시험해 정한다.
- **이유**: 식초 양말이 물 양말과 방향 5~6° 로 구분 안 됨(센서가 물기에 반응). 데이터시트 보증 대상은 VOC·황화합물.

### 2026-10-27 · 데모 = 식초 뿌린 양말 (보류 — 위 항목)
- **결정**: 식초를 물에 섞어 양말에 뿌리고 와드 센서에 갖다 대면 → 악취 감지 → 공기청정기가 이동해 작동 + 발향.
- **이유**: 실제 생활 악취(발 냄새)에 가까운 연출, 컵보다 짧고 강한 자극이라 감지가 빠름.
- **영향**: 라벨에 `WetSock`(물만 뿌린 양말)·`Sock`(마른 양말) 대조군 추가 — 습도·천 냄새로 켜지지 않는지 확인해야 함. 계획은 [수집_가이드.md](수집_가이드.md).
