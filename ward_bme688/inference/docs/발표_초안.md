# WARD 발표 초안

> 사용법: `## 슬라이드 N` 하나가 한 장. `>` 줄은 발표 대본(노트). Gamma·Canva·Google Slides 에 붙여 넣어 시작한다.
> 숫자는 [실험_결과.md](실험_결과.md) 에서 가져오고, 바뀌면 둘 다 고친다. 마지막 갱신: 2026-10-27

## 슬라이드 1 — WARD: 냄새를 구분하는 공기청정기
- 퍼스널 발향 + 자율 공기청정
- 우리 향은 그대로, 악취만 치운다
> 향을 뿌리는 공기청정기는 자기가 뿌린 향까지 빨아들입니다. WARD 는 향과 악취를 구분합니다.

## 슬라이드 2 — 문제
- 일반 공기청정기: 향·악취 구분 없이 VOC 수치만 보고 동작
- 디퓨저와 같이 쓰면 향을 지워 버림
> 실제로 공기청정기를 켜면 센서에 닿는 향이 1/10 로 줄었습니다.

## 슬라이드 3 — 시스템 구성
- 와드(가스센서 8개, 배터리) → MQTT → Jetson 판정 → 공기청정기·대시보드
- (그림: 시스템_구조.md 의 구성도)

## 슬라이드 4 — 센서가 냄새를 보는 방법
- 금속산화물 가스센서: 히터 온도별 저항 변화
- 10단계 온도 × 8센서 = 냄새 하나당 숫자 80개
- 히터 온도 단계를 직접 설계 (기본 설정의 100℃ 단계 포화 문제 해결)

## 슬라이드 5 — 판정 방법
- 평소 공기와의 차이(Δ) → 세기와 방향
- 세기 0.3 이상만 판정, 방향이 가장 가까운 냄새로 분류
- 8센서 표결 + 30초 연속 조건 → 청정기 ON
> 날마다 흘러가는 센서 값을 차이로 지우고, 농도에 덜 흔들리게 방향으로 비교합니다.

## 슬라이드 6 — 왜 AI-Studio 가 아니라 직접 만들었나
- 클래스 4개 제한, 처음 보는 냄새 처리 없음
- 무작위 분할 점수는 부풀려짐 (F1 0.977 → 녹화 분리 0.000 사례)
- 날짜 분리 검증·기준선 처리를 우리가 통제

## 슬라이드 7 — 실험 결과
- 우리 향 3종끼리 2~4°, 커피와는 11~24°
- 세기별 정확도 표 → 문턱 0.3
- 리허설: 커피 5/5 1분 안에 감지
- 모델 비교: 전처리가 모델보다 중요

## 슬라이드 8 — 어려웠던 점과 해결
- 센서 위치(30cm 벗어나면 반응 0) → 위치 고정·팬
- 남은 향이 기준선을 밀어냄 → 청정기 켠 채 회복
- 배터리 방전 리셋 → 완충·히터 점검 도구

## 슬라이드 9 — 데모 시나리오
- 깨끗한 공기 → 라벤더 분무(청정기 꺼짐 유지) → 식초 등장 → 30초~1분 안에 경고 + 청정기 ON → 치우면 OFF

## 슬라이드 10 — 앞으로
- 향 이름 구분(다른 날 90%) 검증
- 공기질(IAQ) 표시 추가
