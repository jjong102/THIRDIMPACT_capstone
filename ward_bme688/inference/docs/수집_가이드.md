## 판정과 청정기 동작

| 라벨 | 무엇 | 청정기(출동) |
|---|---|---|
| `Air` | 공기 (청정기 꺼짐·켜짐 둘 다) | 끔 |
| `Peppermint` `Lavender` `Orange` | 우리 향 (로봇 가습기 발향) | **끔** — 발향 중 다시 출동하면 안 됨 |
| `Vinegar` | **식초에 적셔 말린 양말**을 센서에 댐 | **켬** |
| `Sock` · `WetSock` | 마른 양말 · 물에만 적셔 말린 양말 (대조군, 11/02 증명 완료) | 끔 — 학습엔 안 쓰고 재생 평가의 "꺼야 할 구간" |
| `Unk_…` (예: `Unk_양파`) | 처음 보는 냄새 — 학습 안 하고 시험에만 | **켬** |

위험한 실수는 두 가지뿐: **꺼야 할 때 켬**(우리 향에 출동), **켜야 할 때 안 켬**(식초를 놓침).
라벨이 없는 구간(사람·세 향 동시 등)은 학습에 안 들어가고, `replay_eval.py` 가 "라벨 없는 구간 출동"으로 따로 센다.

## 식초 양말 (데모 소품)

**왜 말린 양말인가 (10/27 실측)** — 젖은 양말은 센서가 식초보다 물기(습도)를 봐서 물 양말과 구분이 안 된다.

| 양말 | \|Δ\| 중앙 | 물 양말과 방향 | 우리 향과 방향 |
|---|---|---|---|
| 식초 물을 **뿌린** 젖은 양말 | 0.40 | 5~6° — 구분 안 됨 | 18~19° |
| 식초에 적셔 **2시간 말린** 양말 | 0.57 | **14~16°** — 구분됨 | **27°** |

**레시피 (10/27 확정 — 데모까지 바꾸지 않는다)**
- 물 100 mL + **3배식초 원액 30 mL** 에 살짝 담갔다 뺌 → 한 번 짬 → **약 2시간 자연 건조** → **밀폐 통** 보관.
- 밀폐 통에서 6일 지나도 세기 유지(11/02, \|Δ\| 0.69). **통 밖에 두면 빠진다**(0.69 → 0.49 → 0.27, 11/02). 11/15 여러 번 쓴 양말은 0.12 — 문턱 아래.
- 대기 직전에만 꺼내고, 쓴 뒤 바로 밀폐. 다른 양말과 한 통에 넣지 않는다. **데모용은 2개, 데모 전날 새로 만든다.**
- 대는 법: 청정기 **끈 채로**, 센서 구멍 앞 **2~3 cm**, **60초**. 창문 닫기(11/09 창가에서는 +90초로 늦음).

## 준비물 체크
- [ ] 와드 배터리 충전(UI 왼쪽 아래 와드 카드·`ward_view.py` 에 % 표시, 3.6V 아래 빨강) / USB 는 노트북 본체 포트
- [ ] 와드 팬 돌아가는지 (모든 데이터는 팬 ON 기준). 팬은 녹화 **전에** 켠다 — 녹화 중 켜면 리셋
- [ ] 핫스팟 `third_impact` 켜기 (조원 휴대폰을 와드 근처에 고정, 우빈 휴대폰은 백업 — 끊기면 약 30초 뒤 자동 재연결)
- [ ] 용액 새로: 물 70 mL + **각 40방울** (irha 100% 에센셜 오일). 분무 직전 10번 흔들기
- [ ] 와드·로봇(분무기) 위치를 **데모 배치 그대로**, 줄자·테이프로 표시 — **녹화 중 와드 이동 금지**(들거나 옮기면 잘못 판정)
- [ ] 안 쓰는 분무 통 뚜껑 / 식초 양말 통 밀폐

## 녹화 시작
```powershell
cd C:\2026capston\tools
python mqtt_capture.py --name day6_demo        # 배터리 + WiFi (기본). 자격증명은 Windows 사용자 환경변수
python capture_serial.py --port COM5 --name x   # USB 로 찍을 때 (config.h WARD_WIFI 0 으로 올리면 Brownout 없음)
python ward_view.py                             # 다른 창: 와드 판정 10초마다 (세기 %, 표, 배터리)
```
- 녹화 → `training/recordings/`, 라벨 구간 → `training/data/<라벨>/`.
- 화면에 `[보드 리셋 원인]`·`⚠ 와드 재부팅됨` 이 뜨면 기록해 두고 배터리·팬을 확인한다.
- 예열: 와드를 켜고 **15분 이상** → `python ward_view.py --rebase` 로 기준선 다시 잡기 → "깨끗함" 확인 후 시작.

## 하루 순서 — 데모 배치 (약 65분, 녹화 끊지 않고)

분무는 UI **더보기(톱니바퀴) → 제어 → 향기**에서 **분무 시간 60초**를 고르고 채널을 켠다(60초 뒤 자동으로 꺼짐).
청정기는 같은 화면 공청기 버튼.

| 시작 | 할 일 | 라벨 |
|---|---|---|
| 0분 | 아무것도 안 함 5분 (청정기 꺼짐) | `Air` |
| 5분 | **식초 양말 60초** → 밀폐 | `Vinegar` (앞 10초 빼고) |
| 6분 | 청정기 켜고 회복 6분 → 끄기 | — |
| 12분 | 아무것도 안 함 3분 | `Air` |
| 15분 | **향 ① 60초** + 청정기 **끈 채로 4분** (약하게 남는 구간 — 오판이 나오는 곳) | 그 향 |
| 20분 | 청정기 켜고 회복 5분 → 끄기 → 3분 | `Air`(마지막 3분) |
| 28분 | **향 ② 60초** + 끈 채로 4분 → 회복 → 3분 | 그 향 / `Air` |
| 41분 | **향 ③ 60초** + 끈 채로 4분 → 회복 → 3분 | 그 향 / `Air` |
| 54분 | **세 향 동시 60초** (도착 뒤 발향과 같음) + 끈 채로 4분 | 라벨 없음 (시험용) |
| 59분 | 청정기로 회복 → 깨끗함 → Ctrl+C | — |

- **식초가 먼저**(남은 향 위에서는 묻힌다). 우리 향 세 채널 순서는 날마다 돌린다. 오렌지가 가장 오래 남는다.
- 회복은 **청정기를 켠 채로**. 끄고 기다리면 10분 넘게 안 돌아온다.
- 각 자극 **바로 앞**에 같은 녹화의 평평한 `Air` 가 있어야 기준선이 잡힌다.
- 대조 양말(`Sock`·`WetSock`)은 본 수집에서 생략. 데모 직전 리허설 날 1번만 대서 출동 0 확인(식초보다 먼저).

## 라벨링 (녹화 끝나고 바로)
- Ctrl+C → 라벨링 창. 드래그로 구간 선택 → 숫자키.
- **전환 구간(넣은 직후·치운 직후)은 빼고**, 양말은 60초 중 앞 10초를 뺀다. 향은 반응이 시작된 뒤부터 가라앉을 때까지.
- 조건이 섞인 녹화(채널 실수, 와드 이동 등)는 라벨하지 말고 `training/discarded_<날짜>/` 로 옮기고 [../training/README.md](../training/README.md) 에 적는다.

## 저녁 — 학습·검증·와드 반영 (명령 하나)
```powershell
cd C:\2026capston\tools
python update_model.py            # 학습 → 재생 평가 → 펌웨어 검사 → 통과하면 모델 교체 + model.h
python update_model.py --push     # + 와드로 무선 전송
python update_model.py --rollback # 바로 이전 모델로 (+ --push)
```
- 이전 모델은 `model/history/`. 따로 돌리려면 `open_set.py fit` / `replay_eval.py` / `firmware_parity.py` / `push_model.py`.

## 합격 기준 (학습에 안 쓴 녹화로, 청정기 동작 기준)

| 항목 | 목표 | 11/15 (녹화 8개, 출동 조건 2라운드+강하면 바로) |
|---|---|---|
| 식초 양말 → 출동 | 60초 안 **≥90%** | 10/10, 중앙 21초 · 최대 41초 |
| 꺼야 할 구간(Air·우리 향·대조 양말) 잘못 출동 | **≥98% 끔**, 시간당 1번 이하 | 2번 / 224분 |
| 발향 중·직후 다시 출동 | 0번 | 미검증 — 데모 배치 수집 필요 |

못 미칠 때:
- 우리 향을 식초로 오판 → 그 향의 약한 구간을 더 모아 재학습, 발향 잠금(`SPRAY`)을 식초 판정까지 넓히는 안 비교.
- 식초를 놓침 → 새 양말, 더 가까이, 대는 시간 늘리기.
- 공기에서 출동 → 예열을 더 길게, `--rebase`, 와드를 움직이지 않았는지.
